# 养成系统设计（GAMEPLAY）

> 主线玩法移植自 whale 的养成模块，落库见 `DATA-MODEL.md`。

## 1. 数值体系

| 数值 | 范围 | 变化来源 | 落库 |
|---|---|---|---|
| 心情 mood | 0–100 | 夸夸↑ / 戳一下↓ / 投喂↑ / 久置↓ | `pet_state.mood` |
| 好感 affinity | 累计 | 互动、完成任务、签到 | `pet_state.affinity` |
| 饱食 satiety | 0–100 | 投喂↑ / 随时间↓ | `pet_state.satiety` |
| 等级 level | 1+ | 经验累积升级 | `pet_state.level` |
| 经验 exp | — | 互动/任务/陪伴 | `pet_state.exp` |
| 羁绊 bond_level | 1–7 | 好感/陪伴达标解锁 | `pet_state.bond_level` |
| 连续签到 streak | 天 | 每日签到 | `pet_state.streak_days` |
| 陪伴时长 companion | ms | 运行时累计 | `pet_state.companion_ms` |

**升级曲线**：`exp_needed(level)` 单调递增（沿用 whale 的难度阶梯，具体常数在实现期标定）。

## 2. 羁绊等级解锁

| 等级 | 解锁内容 |
|---|---|
| Lv3 | 新待机动作 |
| Lv5 | 称号「鲸汐守护者」 |
| Lv7 | 隐藏彩蛋 |

## 3. 成就系统（39 项）

分类（沿用 whale）：

| 类别 | 说明 | 数量级 |
|---|---|---|
| 互动类 | 摸头/戳/投喂/三连击等 | ~10 |
| 陪伴类 | 陪伴时长、连续签到 | ~8 |
| 养成类 | 等级、羁绊、心情里程碑 | ~8 |
| 任务类 | 完成每日任务/签到 | ~6 |
| 小游戏类 | 预留（本期不判定） | ~7 |

- 判定在 `AchievementService`，解锁写 `achievements` 表并计入成长日记。
- 设置面板内提供**成就墙**（已解锁高亮、未解锁灰显）。

## 4. 每日任务

- **3 个任务槽**，每日（按 `day_key`）自动刷新。
- 完成领取好感/经验奖励；`quests` 表记录进度与领取状态。

## 5. 周签到

- 本周签到板 **7 格**；集满 **1 / 3 / 7** 天有里程碑奖励。
- `signin` 表按 `week_key` 记录。

## 6. 成长日记

- 记录关键节点（羁绊升级、成就解锁、任务完成）。
- 设置面板倒序展示最近 **12 条**，标注相对时间。
- 同一天同类事件只记一条；最多保留 **80 条**。

## 7. 投喂与互动对数值的影响

| 交互 | 效果 |
|---|---|
| 投喂小点心 | 饱食↑、好感↑，触发吃东西立绘 |
| 夸夸 | 心情↑、好感↑，星星眼 |
| 戳一下 | 心情↓，生气立绘 |
| 摸头（分区） | 脸红立绘 + 爱心特效，好感↑ |

## 8. 时间驱动

- 饱食度按时间衰减（定时结算 tick）。
- 连续签到按自然日判定；跨天触发新一天任务刷新。
- 深夜（23:00–05:59）不主动打扰（与状态机规则一致）。
