# ROADMAP · P5 — 梗聊天

> 未完成阶段，完成后重命名为 `ROADMAP-P5-Fin.md`。

## 阶段目标

接入 whale 台词库与关键词表情感知，实现「陪伴式」闲聊（本项目保留的唯一延伸功能）。

## 交付物

- `ChatService` + `LineTable`（外部台词语料）。
- 分时问候 / 心情分层 / 羁绊专属台词。
- 13 关键词 → `meme-*` 表情感知。
- 说话节流与「不打断」规则。

## 任务清单

1. 迁移 whale `LINES` 台词库到 `assets/lines/`（按场景分文件）。
2. 实现 `LineTable` 解析与场景查询；缺失文件优雅降级（空表 + 日志）。
3. 实现 `ChatService`：候选选取、最近 N 条去重、≥6s 节流。
4. 分时问候（早/上午/中/下午/傍晚；深夜静默）。
5. 心情分层选词（低落温柔 / 高涨元气）。
6. 羁绊 Lv3/5/7 专属台词。
7. 关键词表情感知：`keyword_aware` 开关（默认关），命中切 `meme-*`。
8. 单测：场景选词、去重、节流、关键词映射、开关关闭不触发。

## 验收标准

- [ ] 待机/互动时气泡台词自然出现且不重复、不刷屏。
- [ ] 分时问候与深夜静默生效。
- [ ] 关键词命中时立绘切换为对应表情（开关开启时）。
- [ ] 台词语料可外部替换且不影响主程序。
- [ ] ChatService 单测通过。
