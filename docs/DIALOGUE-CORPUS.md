## 1. 风格基线（与项目一致）

- **人设**：鲸鱼娘；第一人称自称「鲸鱼娘」或「我」，称呼用户为「主人」。
- **语气**：软萌爱撒娇，带「嘴硬 / 毒舌 / 傲娇」反差 —— 先嘴硬三分、再心软七分，关心主人作息与健康。
- **句式**：口语化语气词（呀 / 哦 / 啦 / 嘛 / 诶嘿 / 哼哼），句尾 1–2 个 Emoji，
  偶用括号动作描写（（转了个圈）（小声）（拍拍胸口））。
- **三条回答的关系**：同一 slot 组内互相替换、不重复；三条可分别为「元气 / 嘴硬 / 温柔」等不同侧面，
  但都必须成立为对同一问题的自然回答。
- **尺度声明**：私密问答为**全年龄向**的暧昧 / 依赖 / 恋爱暗线（与既有 `q-savings` / `q-crush` 同级），
  不含任何露骨内容。

## 2. 接入口径（对齐既有机制）

| 项 | 约定 |
|---|---|
| category | 普通问答 → `normal`；私密问答 → `sensitive`（沿用 `q-` 前缀 id 风格） |
| id | 本清单已按语义给出（如 `q-name` / `q-first-meet`），与既有 id **不冲突** |
| slot | 每题 **3 条候选**（`slot 0` / `1` / `2`），与现行系统「每题三个预设回答、随机取一」口径完全一致；可直接按 `q|` / `a|` 格式落库，无需再补候选 |
| 私密门槛 | 好感度 ≥ `kSensitiveUnlockAffinity`（5000）且每日 ≤ `kSensitiveDailyLimit`（3）次（`DialogueOptions.h`） |
| 立绘机制 | 现行池：`normal` → `curious`；`choice` → `meme-no` / `meme-yes`；`sensitive` → `meme-broke` / `meme-cry` / `meme-heart`（`DialoguePoseRules.h`）。本清单立绘列为**建议值**，真正生效需同步调整池定义 |

## 3. 立绘接入判断口径

> 判断以**题目为单位**（覆盖该题三条回答的共同情绪方向；三条情绪差异较大时给出主 / 备两个 key）。

| 标记 | 含义 | 接入建议 |
|---|---|---|
| ✅ 专属 | 该题回答有明确情绪 / 表情动作，配立绘显著增益 | 为该题建议专属表情（给出 pose key 与表情方向） |
| ✅ 通用 | 情绪温和，适合接入但不必专属 | 沿用该类默认立绘即可（如 `normal` → `curious`） |
| ❌ | 纯操作指引 / 事实说明，配强情绪会违和 | **不新增专属立绘**，沿用该类默认立绘 |
