# 梗聊天设计（CHAT）

> 保留范围：**仅梗聊天**（whale 的天气/余额/TTS/无障碍全部移除）。

## 1. 台词库组织

- **不硬编码进 C++**，以外部资源承载（便于个人替换）。
- 建议位置：`assets/lines/`，按场景分文件（如 `idle.txt` / `waiting.txt` / `work.txt` / `evening.txt`…）。
- 每条台词标注所属**场景 key**（与 `STATE-MACHINE.md` 的 pose/场景对应）。
- 规模：沿用 whale 的 **530+ 条**（可裁剪/精简，个人使用可自定）。
- 来源：`referances/dsh-whale-musume/assets/whale-moe-core.js` 中的 `LINES` 常量，迁移为独立文本资源。

## 2. 分时问候

| 时段 | 场景 key |
|---|---|
| 早上 / 上午 / 中午 / 下午 / 傍晚 | `greet-*` |
| 深夜 23:00–05:59 | 不主动发言（点击等主动交互豁免） |

## 3. 心情分层台词

- 心情**低落** → 温柔向台词；**高涨** → 元气向台词。
- 羁绊等级 **Lv3 / Lv5 / Lv7** 解锁专属台词（对应 `GAMEPLAY.md`）。

## 4. 关键词表情感知（13 种梗）

| 关键词触发 | 表情立绘 |
|---|---|
| kyun / OMG / doge / sike / 膜拜 / peace / 怀疑人生 / waku waku 等 13 项 | `meme-*` 对应立绘 |

- 命中即在气泡中间切换为表情立绘。
- **默认关闭**（沿用 whale 对隐私/打扰的谨慎），用户可在设置中开启。
- **本项目无聊天输入源**：触发源为**用户自定义热词**或（可选）本地剪贴板/输入内容匹配；定位为「个人用的趣味反应」，不接入任何外部聊天。

## 5. 说话节流与打断规则

| 规则 | 值 / 行为 |
|---|---|
| 最小间隔 | ≥ 6000ms（`SPEECH_GAP_MS`） |
| 拖拽中 | 不发言 |
| 小游戏/设置打开时 | 不主动发言 |
| 深夜 | 不主动发言 |
| 连续两条 | 避免重复同一条（最近 N 条去重） |

## 6. 数据流

```
事件/定时 → ChatService.pick(sceneKey, mood, bondLevel, recentLines)
          → LineTable 查询候选 → 去重/节流过滤 → 选出 1 条
          → (可选) 关键词匹配 → pose(meme-*) 或普通 pose
          → Presenter 显示气泡
```

## 7. 配置项

- `bubble_enabled`：气泡开关。
- `keyword_aware`：关键词感知开关（默认关）。
- 台词库路径：可指向外部目录，便于个人改写。

## 8. 明确移除

- 天气台词、余额播报、TTS 播报、无障碍 aria 播报。
- 依赖宿主 DOM 的「检测工具运行」联动。
