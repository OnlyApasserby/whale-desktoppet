# 预设问答语料（P8）—— **主人提问 → 鲸鱼娘回答**（docs/DIALOGUE.md）
#
# 格式（不要改动分隔符）：
#   q|<id>|<category>|<问题文本>      ← 主人（用户）可以问的问题
#   a|<id>|<slot>|<回答文本>          ← 鲸鱼娘的回答；同一 slot 可写多条候选
#
#   * category：
#       - normal    日常问题（五选一里的「随机三选」候选）
#       - choice    选择类问题（同上，立绘走 meme-no / meme-yes 独立池）
#       - sensitive 敏感 / 私密问题（五选一里的**固定槽位**；
#                   好感度 ≥ 5000 解锁，每日最多 3 次）
#       - weather   天气问题（五选一里的**固定槽位**；
#                   **未配置彩云天气 key + 城市时不可用**）
#   * slot：normal / choice / sensitive 为 0 / 1 / 2 —— **每个问题三个预设回答**，
#           主人选中问题后由程序随机取其中一个；
#           weather 为天气类型 id（sunny / cloudy / overcast / rain / snow / fog /
#           thunder / hail / unknown），由彩云天气 API 判定后取该类型下的回答。
#   * 同一 (id, slot) **可写多条**：它们在同一个台词场景 key 下随机取一条，
#     用于「天气题也保证三个预设回答」这类需要多候选的情况。
#
# `#` 与空行忽略。
