# 预设问答语料（P8）—— **主人提问 → 鲸鱼娘回答**（docs/DIALOGUE.md）
#
# 格式（不要改动分隔符）：
#   q|<id>|<category>|<问题文本>      ← 主人（用户）可以问的问题
#   a|<id>|<slot>|<回答文本>          ← 鲸鱼娘的回答；同一 slot 可写多条候选
#
#   * category：
#       - normal    日常问题（五选一里的「随机三选」候选）
#       - choice    选择类问题（同上，立绘走 meme-no / meme-yes 独立池）
#       - sensitive 敏感 / 私密问题（五选一里的**固定槽位**；
#                   好感度 ≥ 5000 解锁，每日最多 3 次）
#       - weather   天气问题（五选一里的**固定槽位**；
#                   **未配置彩云天气 key + 城市时不可用**）
#   * slot：normal / choice / sensitive 为 0 / 1 / 2 —— **每个问题三个预设回答**，
#           主人选中问题后由程序随机取其中一个；
#           weather 为天气类型 id（sunny / cloudy / overcast / rain / snow / fog /
#           thunder / hail / unknown），由彩云天气 API 判定后取该类型下的回答。
#   * 同一 (id, slot) **可写多条**：它们在同一个台词场景 key 下随机取一条，
#     用于「天气题也保证三个预设回答」这类需要多候选的情况。
#
# `#` 与空行忽略。

# ---------------------------------------------------------------------------
# 日常（normal）—— 随机三选的候选池
# ---------------------------------------------------------------------------
q|q-mood|normal|今天心情怎么样呀？
a|q-mood|0|还不错！看到主人来问我就更好了
a|q-mood|1|有一点点累，不过陪你待一会儿就缓过来了
a|q-mood|2|好得想原地转三圈！主人要不要也开心一点

q|q-tired|normal|累不累？要不要休息一下？
a|q-tired|0|不累不累，我可是鲸鱼，力气大得很
a|q-tired|1|有一点点……那我把鳍搭在你肩膀上歇会儿
a|q-tired|2|主人先休息吧，我帮你守着屏幕

q|q-food|normal|你喜欢吃什么呀？
a|q-food|0|小鱼干！还有你投喂的一切
a|q-food|1|甜甜的东西，最好是能分你一半的那种
a|q-food|2|我不挑食，但你喂的会格外香

q|q-cute|normal|你觉得自己可不可爱？
a|q-cute|0|这个嘛……你心里不是已经有答案了吗
a|q-cute|1|可爱是我与生俱来的，拒绝反驳
a|q-cute|2|（转了个圈）现在呢，可爱加倍了吧

q|q-plan|normal|周末想做什么呀？
a|q-plan|0|睡到自然醒，然后趴在你旁边发呆
a|q-plan|1|想去有风的地方，把烦恼都吹走
a|q-plan|2|把想做的事列一长串，最后躺平。计划通

q|q-wish|normal|有什么小愿望吗？
a|q-wish|0|希望主人每天都能顺顺利利的
a|q-wish|1|想被你多摸一会儿头，这算不算
a|q-wish|2|愿望说出来就不灵了，所以先保密

# ---------------------------------------------------------------------------
# 选择（choice）—— 随机三选的候选池（立绘走 meme-no / meme-yes）
# ---------------------------------------------------------------------------
q|q-hotpot|choice|今天吃火锅好不好？
a|q-hotpot|0|好！必须好！毛肚我先下
a|q-hotpot|1|不了不了，胃在抗议，改天吧
a|q-hotpot|2|你请客的话，我立刻就位

q|q-latenight|choice|今晚要不要一起熬夜？
a|q-latenight|0|熬夜可以，但明天不许说我没提醒你
a|q-latenight|1|不熬了，早点睡才是正经事
a|q-latenight|2|陪你可以，不过我一到点就会打瞌睡哦

# ---------------------------------------------------------------------------
# 敏感 / 私密（sensitive）—— 固定槽位；好感度 ≥ 5000 解锁，每日 3 次
# ---------------------------------------------------------------------------
q|q-savings|sensitive|你的存款有多少呀？
a|q-savings|0|这个嘛……是我的小秘密，说出来会漏财的
a|q-savings|1|够买很多很多小鱼干，再多就不告诉你啦
a|q-savings|2|（捂住钱包）主人问得太直接啦，我脸红

q|q-crush|sensitive|你有喜欢的人吗？
a|q-crush|0|有呀……不过名字暂时保密
a|q-crush|1|这个问题会让我心跳变快，换一个好不好
a|q-crush|2|（小声）喜欢的类型，就坐在屏幕前面那个

# ---------------------------------------------------------------------------
# 天气（weather）—— 固定槽位；未配置彩云 key + 城市时不可用
# 回答按天气类型分组，每个类型三条候选（随机取一条）
# ---------------------------------------------------------------------------

a|q-weather|snow|下雪了，路面很滑，要小心

a|q-weather|thunder|雷雨天最适合待在家里，我们一起躲着

a|q-weather|unknown|天气我还没查到，不过伞备着总没错
